# Harmon Code

Código-fonte e aplicação para Harmon.

Este é um repositório público: https://github.com/belclei/harmon-code

## Setup

```bash
npm install
docker compose up -d   # Postgres + Redis (once per machine; leave running)
npm run dev            # API (:3001) + web (:5173) together
```

Veja documentação em ../ (repo privado) para arquitetura e design system.
